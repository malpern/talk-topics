# Household Atlas public showcase

A landing page and standalone synthetic demo for the Hacker Dojo talk index. The page leads with six practical questions about shopping habits and decisions, includes six actual screenshots of synthetic app views, and offers a copyable starting prompt with browser/file-access prerequisites. The ChatGPT/Codex-assisted build story follows the viewer-facing content. The application source repository is private and intentionally not linked.

- `index.html`, `style.css`, `page.js`: public case study and screenshot gallery.
- `starter-prompt.txt`: downloadable agent-independent brief, identical to the page’s copyable prompt. Copying falls back to selecting text if clipboard access is denied.
- `assets/`: actual 1280×720 browser captures of the synthetic overview, comparison, savings, electronics, book topics, and audiobook views. No real household data is shown.
- `demo/index.html`: self-contained synthetic app, including the DialKit MIT license. No private dataset or account connection.
- `demo/DIALKIT-LICENSE.txt`: standalone license copy.

The sample catalog, dates, identifiers, amounts, returns and trends are fictional. This is an illustrative household, not a measured population average. Downloaded demo CSV and JSON records are labeled synthetic.

Before publishing updates, verify that the demo artifact matches the approved public build, inspect each screenshot, check links and image alt text, and scan all added content for private identifiers, source paths, narratives, and repository links. Keep real household reports and private source files out of this repository.

Finite navigation/dialog entrances, reduced-motion handling, press feedback, keyboard focus restoration, review confirmation, and recoverable empty/startup-error states are bundled in the demo.
