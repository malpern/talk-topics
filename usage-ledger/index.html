01 / Why measure?

A model name is not a billing route.

One completed job can contain many model calls. A failed attempt can still consume tokens. A subscription credential does not prove that a request used included allowance. And a small local slice in a chart can simply mean local usage was not recorded.

Usage Ledger keeps those distinctions visible. It collects metadata from OpenClaw, supported native client records and local Ollama workflows. Its private dashboard separates workflow totals from model-response records, keeps unknown measurements explicit and surfaces tasks worth investigating.

ObserveRecord tokens and execution evidence without retaining prompts or answers.
ExplainIdentify context-heavy tasks, missing measurements and uncertain billing.
EvaluateCompare quality before promoting a smaller or local model.

03 / Privacy by separation
A demo, not a window into my account.
The live ledger and dashboard stay on a private Tailscale network. This public page contains only an explicitly selected, frozen example. It has no connection to the live database and cannot refresh or query private history.
  • No prompts, model answers, email or calendar contents.
  • No credentials, account identifiers or private dashboard address.
  • No live usage feed or hidden connection to private systems.
  • No automatic model changes based on token counts.
The next step is controlled comparison: hold the evidence constant, review the expected result and only promote local processing when it meets the task’s quality requirements.
