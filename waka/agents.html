The contract: pixels in, direction out

Your policy runs as a separate process. A trusted Waka gateway owns the simulation, network socket, and checksums. It supplies the released gameplay image through stdin and accepts a direction through stdout.

Released image224 × 288 pixels
→
Your policyObserve · remember · decide
→
DirectionNext shared input boundary

The policy package has no simulation, game-data, or networking dependency. Its observation contains no actor objects, ghost targets, exact timers, seeds, house counters, hidden movement phases, or future state.

You may remember images, infer motion, and plan. Those are policy computations. The interface does not provide an OS sandbox, equal computing power, or proof that someone else’s modified client is honest.

Connect a policy

For the bundled reference agent, press G in Waka. For your own policy, start an Equalized host with H, then 1. Connect the gateway as its second participant.

Mac

Terminal
/Applications/Waka.app/Contents/MacOS/Waka --agent-connect HOST:24880 --policy python3 my_agent.py

Linux

Terminal
./Waka --agent-connect HOST:24880 --policy python3 my_agent.py

Windows PowerShell

PowerShell
.\Waka.exe --agent-connect HOST:24880 --policy python my_agent.py

Replace HOST with the host’s reachable address. When both run on the same machine, use 127.0.0.1. The argument immediately after --policy is the executable; all remaining arguments are passed to it. Quote paths containing spaces. No shell expansion is performed by Waka.

The gateway refuses Responsive sessions. Launch policies you trust: they run with your user account’s ordinary permissions.

Read an observation

Each stdin line is one UTF-8 JSON object, terminated by a newline. Version 1 uses row-major RGB run-length encoding. The origin is the top-left corner; x increases right and y increases down.

JSONL / valid all-black example
{"version":1,"frame":42,"player":1,"delay_ticks":24,
 "width":224,"height":288,"runs":[[64512,0]]}
FieldMeaning
versionProtocol version. Currently 1.
frameReleased presentation frame. Echo it in your response.
playerYour assigned slot: 0 yellow, 1 cyan.
delay_ticksPublic session input plus presentation buffering. Normally 24 in Equalized.
width, height224 and 288.
runsPairs of positive pixel count and RGB24 integer (0xRRGGBB). Counts must total 64,512.

The image is the game framebuffer before optional CRT distortion and machine-local lobby/status overlays. It includes visible HUD and animation cues. No separate audio feed is supplied.

Python / decode pixels
def decode_rgb(observation):
    pixels = bytearray()
    for count, rgb in observation["runs"]:
        color = bytes(((rgb >> 16) & 255, (rgb >> 8) & 255, rgb & 255))
        pixels.extend(color * count)
    assert len(pixels) == 224 * 288 * 3
    return pixels

Observations are published only after the transport releases a frame for presentation. Catch-up may skip intermediate images; do not assume consecutive frame numbers. The policy retains its memory until the gateway process ends.

Send one action

Write a single JSON object and newline to stdout, and flush it immediately.

JSONL / action
{"frame":42,"direction":"up"}

Directions are up, left, down, right, and keep. Keep retains the previous command. A requested turn stays queued until legal; this API does not provide paths, teleportation, pausing, or direct state edits.

Use stderr for diagnostics. Unknown fields, invalid directions, malformed JSON, oversized responses, or closed stdout stop the gateway and end its shared session visibly.

Meet the same clock

  1. Wait for a released image.Frame N becomes eligible only when the common presentation schedule releases it.
  2. Answer promptly.Your matching action must arrive before the next input sample. The game updates every 16,500 microseconds, but the available wall-clock budget can be shorter.
  3. Late means repeat.If no valid action is ready, the previous direction repeats. A late, duplicate, or future-frame answer is discarded. Other players never wait for your policy.

The accepted command goes through the same uniform input delay as keyboard or mouse commands. The gateway buffers at most one outgoing observation in its writer queue, so a slow reader cannot accumulate an unbounded history.

A deadline is not a guaranteed compute budget.Pipe transfer, scheduling, and your process startup use real time. Keep your loop warm, flush stdout, and use a small fast policy before introducing expensive inference. Sleeping is allowed; freezing everyone else is not.

Start with a tiny policy

This executable example proves the process connection; it always requests left and is not a useful game-playing strategy.

Python / example_policy.py
import json, sys

for line in sys.stdin:
    observation = json.loads(line)
    # Replace this fixed direction with your policy.
    action = {"frame": observation["frame"], "direction": "left"}
    print(json.dumps(action), flush=True)

The bundled Rust reference is more capable: it extracts colored components, remembers walls observed in the image, finds paths to visible pellets, assigns costs around visible ghosts, and anticipates junctions using the published delay. It has no fixed replay route.

Test the boundary and the behavior

  • Protocol: decode a frame, validate dimensions/run counts, echo the exact frame ID, and keep stdout free of logs.
  • Deadlines: deliberately sleep or return an old frame number. Your player should repeat its prior input while the rest of the session advances.
  • Observation isolation: changing non-visible timing/queued state must not change the observation. Changing a visible score or removing pixels must affect the displayed image.
  • Gameplay: test both assigned slots, respawns, flickering sprites, tunnels, and the full input/display delay. A local zero-delay clear is not proof of network play.
  • Portability: builds, tests, dependency checks, and packaged launches run on Mac, Linux, and Windows.

Physical cross-machine display timing under load remains a separate qualification task. Do not present the API boundary as a hardware fairness or anti-cheat guarantee.
