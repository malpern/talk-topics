01 / FIRST FIVE MINUTES

From blank file to first points.

This guide is for the new macOS classroom build. Older Waka preview downloads and the browser arcade do not include it. Build the current source with python3 scripts/package.py, or use the classroom app your instructor provides.

  1. Open File → Settings… in Waka. Enable Python Agent Classroom Mode. The default roster has two of each of six built-in strategies. Start a round to see their differences.
  2. Save the Starter Kit. Use the button in Settings or download this ZIP. Python 3.9 or newer is required; there are no pip dependencies. In Settings, select your Python executable or virtual environment.
  3. Edit starter_agent.py. You only need a function that receives a dictionary and returns a move. The optional waka helpers are provided by the host.
  4. Load your agent into any roster slot. Choose Load .py…, select your file, name your agent, and start a new round. Every round reloads your saved code.
starter_agent.py · complete runnable agent
from waka import nearest


def decide(observation, memory):
    memory["turns"] = memory.get("turns", 0) + 1
    return {
        "move": nearest(observation, observation["pellets"]),
        "signal": "Learning by doing",
    }

You already know enough if you can use functions, dictionaries, lists and loops. Breadth-first search is the next useful idea; open waka.py to read a short, working implementation.

02 / HOW A TURN WORKS

Observe. Decide. Move together.

01

See the board

The host sends every agent the same public arena state, with its own ID and legal moves.

02

Pick a direction

Your function returns before the common deadline. The default is 100 ms.

03

Resolve the turn

All moves happen together, then pellets, vaults, bounties and ghosts resolve.

A game second is eight ticks. The map is 81 columns × 55 rows: [x, y] starts at the top left; x grows rightward and y grows downward. A legal move travels one tile. Walls block movement. Multiple agents can occupy a tile; head-on swaps are allowed.

Each pellet is worth 10 points. Agents reaching it together split the points; any remainder rotates by agent ID and tick. Every 80 ticks, the seeded host adds pellets at up to 100 sampled floor cells. Highest score wins when time expires; tied scores share a place. There is no elimination from in-game collisions.

The classroom gives you structured, public information for learning. It has its own rules and scoring; Waka’s existing two-player, image-only arcade agent protocol is a separate interface.

03 / YOUR PYTHON CONTRACT

A dictionary in. A decision out.

Define decide(observation, memory). memory is your private Python dictionary, kept for the whole round and reset on the next round. It may contain sets, tuples or a random.Random object; it is not serialized. Editing the observation does not change the game.

FieldWhat you get
youYour zero-based ID. agents[you] is your agent.
tick, ticks_leftInteger game time. Tick 0 is the first decision.
grid, width, height55 strings of length 81. # is wall, . is floor. A dot in the grid does not mean a pellet remains.
pelletsRemaining pellet positions as [[x, y], ...].
agentsEach has id, name, position, score, signal, active, status, faults, detail, color. IDs stay stable, including stopped agents.
legal_movesDirections that avoid walls from your current tile, always including stay.
rulesBooleans: vaults, portals, bounty, storms.
vaultsObjects with id, pads, ready_at. Each has two pad coordinates. Empty when disabled.
portalsObjects with position, destination. Routing changes every 80 ticks; portal_shift_in is the countdown. Empty when disabled.
leader, bounty_ready_atLeader ID (or None when disabled), and the next tick when a tag may pay out. Tied leaders use the lowest ID for the crown only.
ghostsVisible storm ghost coordinates. storm_warning announces arrival; storm_in is the countdown or None.
seedYour per-agent random seed. Use it once to initialize a generator in memory.
metricsCumulative counts: pellets_collected, vault_openings, portal_trips, bounty_tags, storm_hits. Useful for comparing rule combinations.
events, done, versionRecent public messages, end-of-round flag and API version (currently 1).

Return either of these

return "left"
# Or attach a public message for other agents next tick:
return {"move": "up", "signal": "Meet at vault 2"}

Moves are up, right, down, left or stay. Signals can contain up to 48 characters. They are just text: your code decides what another agent’s invitation means. A wall move stays in place; it is not a fault.

Build a tiny stateful explorer

This complete strategy prefers the least-visited neighbouring tile and breaks ties with a seeded generator. It is intentionally short; portal-aware routing would be a useful improvement.

Visit memory + reproducible choices
import random
from waka import MOVES, me


def decide(observation, memory):
    if "rng" not in memory:
        memory["rng"] = random.Random(observation["seed"])
        memory["visits"] = {}

    x, y = me(observation)["position"]
    visits = memory["visits"]
    visits[(x, y)] = visits.get((x, y), 0) + 1
    choices = [m for m in observation["legal_moves"] if m != "stay"]
    memory["rng"].shuffle(choices)
    return min(
        choices,
        key=lambda m: visits.get((x + MOVES[m][0], y + MOVES[m][1]), 0),
        default="stay",
    )

05 / CHANGE ONE RULE. WATCH EVERYTHING CHANGE.

Four experiments, each with an off switch.

All four start enabled in Settings. For a first lesson, switch them all off, then add one at a time. Settings changes apply when you start a new round.

COLLABORATION

Co-op vaults

Stand on both pads of a green vault with another agent on the same tick. One pair gets 100 points each; the vault rests for 80 ticks. Pads turn grey while cooling down.

Can rivals agree where to meet without both choosing the same pad?

ADAPTATION

Shuffle portals

Enter A, B, C or D to teleport. Every 80 ticks, each portal’s destination advances around the four exits. The observation always contains the current links. Standing still on an exit does not teleport again.

When is a longer-looking route actually shorter?

COMPETITION

Leader bounty

Tag the crowned leader by sharing a tile or swapping positions. If they have at least 50 points, 50 transfer to one catcher. A shared 40-tick cooldown limits repeat tags; tied catchers rotate priority.

Is chasing the leader worth the pellets you leave behind?

RISK

Ghost storms

Every 160 ticks, an eight-tick warning precedes a 40-tick storm. Four ghosts arrive at the edge midpoints and move toward the nearest agent every other tick. A hit costs 30 points (never below zero) and sends you to a safe spawn tile.

How much score should an agent sacrifice to stay safe?

These are playable first experiments, not claims of perfect balance. Use the seed, toggles and exported action log to compare strategies and tune your classroom’s challenges.

06 / DEBUG WITH EVIDENCE

Your best tool is a paused turn.

  • Pause, then Step One Tick. Follow one decision at a time. Select an agent in the leaderboard to highlight it, see its coordinates, read its signal and inspect its last error.
  • Missing Python? Install Python 3.9+ using your normal setup, then choose its executable in Settings. For a virtual environment, select its bin/python. The app does not install packages for you.
  • Syntax error or missing function? The roster shows a startup error and stops that agent; the rest of the round continues. The function must be named decide and take two arguments.
  • Exception or invalid move? The agent stays for that tick. Three faults in a round stop it. A deadline miss stops its process immediately, so a hung function cannot stall everybody.
  • Too slow? Avoid a full search for every candidate destination. One BFS can find the nearest of many targets. Use memory to reuse work. Raise the common decision budget for teaching, then lower it for comparison.
  • Use signals for live debugging. For example {"move": move, "signal": f"target={goal}"}. Ordinary print() output is drained safely; it is not a live console. Startup tracebacks may appear in the last-error detail.
  • Export the round. The JSON contains settings, the final snapshot, accepted actions and stopped-agent IDs by tick. It records what happened even if wall-clock timing varied.

Run a batch without opening a window

From the unzipped starter kit, edit sample-config.json to set your roster, seed, rules and round length, then run:

python3 runner.py --config sample-config.json --headless --result result.json

Inspect result.json with Python’s json module. The host runs on macOS and other POSIX systems; the native Settings and arena display are macOS-only. Headless mode runs as quickly as decisions allow. The same seed reproduces seeded events; use the exported accepted actions to explain differences caused by timeouts or unseeded student randomness.

Trust boundary: Python files run as your local user with normal file and network access. Separate processes and deadlines protect play from ordinary mistakes; they are not a security sandbox. Review student submissions before running them on your own machine.

07 / A CLASSROOM THAT LEARNS TOGETHER

One session. Four useful questions.

TimeBuildDiscuss
0–10 minRun the Forager, all experiments off.What does the observation tell you? What does it leave to your code?
10–25 minAdd visit memory or a distant goal.Why do two locally sensible agents sometimes follow the same route?
25–40 minEnable vaults. Agree on a signal convention.How will partners choose different pads? When should waiting end?
40–60 minAdd one other experiment, then run the full roster.Which strategy adapts? Which assumption breaks?

Make comparison fair enough to learn from

Keep round length, decision budget and rule toggles fixed. Compare at least five seeds. Rotate students through different roster slots so spawn location and tie-breaking do not decide your conclusion. Report average score alongside failures and worst-case score. Agree whether partner coordination is allowed before a tournament.

Stretch projects

  • Team protocol: define vault:2:left signals and handle abandoned invitations.
  • Risk model: penalize paths near ghosts rather than banning them outright.
  • Portfolio agent: switch between hunting, exploring and cooperating using score and remaining time.
  • Experiment notebook: chart results across seeds and rule combinations using exported JSON.
