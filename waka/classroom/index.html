01 / FIRST FIVE MINUTES

Write a brain for the maze.

The revised classroom has a compact 41 × 37 maze, symmetrical wall islands, a central ghost pen, narrow passages, side tunnels and fixed teleport pairs. Eight colored, chomping players compete while eight ghosts scatter, chase, turn blue and return to the pen after being eaten. The Mac app supplies original synthesized arcade sounds.

Use the new classroom build from your instructor, or build the codex/python-classroom-mode source branch with python3 scripts/package.py. Older published Waka downloads and browser play still use the original arcade modes.

  1. Open Waka → File → Settings… Enable Python Agent Classroom Mode. Start the eight example strategies to get a feel for the maze.
  2. Save the Starter Kit. Use the Settings button or download the ZIP. Select Python 3.9+ or a virtual environment in Settings. No third-party packages are needed.
  3. Edit starter_agent.py. Define decide(observation, memory). Start with safe dot collection, then add your own priorities.
  4. Load your file into a roster slot. Click Load .py…, choose the file, and start a new round. Your saved code reloads every round.
A complete first agent: survive, then forage
from waka import emergency, nearest, danger


def decide(observation, memory):
    escape = emergency(observation)
    if escape is not None:
        return {"move": escape, "signal": "Escaping danger"}

    return nearest(
        observation,
        observation["pellets"],
        avoid=danger(observation),
    )

Functions, dictionaries, lists and loops are enough to begin. The supplied helpers are readable Python, not a black box: open waka.py to learn the breadth-first search behind routing and escape decisions.

02 / HOW A TURN WORKS

One snapshot. Simultaneous decisions.

01

Observe

Every agent sees the public maze, ghosts, power-ups and player states. Your ID identifies your player.

02

Decide

Return a direction within the common budget: 100 ms by default. Memory persists between turns.

03

Resolve

Players move, pickups resolve, ghosts move, ghost combat resolves, then predators eat players.

Eight ticks make one game second. An ordinary move travels one tile; a blocked move stays in place. Predators take one extra step along a straight corridor on even ticks, stopping at junctions so they can still choose a turn. Positions are [x, y], starting at the top left. Players may share a tile or swap places. A collision includes a head-on swap. Picking up a power pellet happens before combat, so it can save you on the very same tick.

Dots score 10. Simultaneous collectors split the points, with rotating remainder priority. Clearing every dot refreshes the board. Ghosts move three ticks out of four while dangerous and every other tick while frightened. Their eight authored personalities include chasers, ambushers, a guardian, a stalker and an interceptor; brief scatter intervals create breathing room.

A dangerous ghost costs you 50 points, never below zero. You return after one second with a three-second shield. Eaten ghosts return as eyes, wait in the pen, and rejoin the chase. There is always one ghost object per roster player; in-game deaths never permanently eliminate either side.

The winner has the most points when the round ends. Tied scores share a place. This is an authored classroom game inspired by the arcade, with its own rules and API; the original two-player, image-only Waka protocol remains separate.

03 / YOUR PYTHON CONTRACT · VERSION 2

Ask what is safe. Then what is worth it.

Return a direction string or a dictionary with move and an optional public signal of up to 48 characters. Directions are up, right, down, left, stay. Signals reach other agents on the next tick. Your memory dictionary is private, can hold arbitrary Python objects, and resets between rounds.

FieldWhat you get
you, agentsYour zero-based ID and all player objects. agents[you] is you. Player fields: id, name, position, direction, score, alive, active, predator_ticks, shield_ticks, respawn_ticks, deaths, captures, signal, status, detail, faults, color.
ghostsObjects with id, name, style, position, direction, color, state, release_at. State is chase, frightened, eyes or house. Only chase ghosts hurt you; frightened ghosts are edible.
powerupsObjects with id, kind, position, available, ready_at. Kind is energizer, predator or fruit. The cooldown station stays in the API, but only available pickups can be collected.

A practical predator policy

Check danger first. Then look for prey you can reach before your power expires. Both shields and another predator power protect opponents from being eaten. A long chase can be worse than collecting nearby dots.

Try a timed hunter
from waka import (
    emergency, me, route, vulnerable_players,
    pickups, nearest, danger,
)


def decide(observation, memory):
    escape = emergency(observation, radius=2)
    if escape is not None:
        return escape  # Predator power does NOT stop ghosts.

    own = me(observation)
    if own["predator_ticks"] and not own["shield_ticks"]:
        prey = [a["position"] for a in vulnerable_players(observation)]
        move, travel = route(observation, prey, avoid=danger(observation))
        if travel is not None and travel + 3 < own["predator_ticks"]:
            return {"move": move, "signal": "Hunting while I can"}

    goals = pickups(observation, "predator") or observation["pellets"]
    return nearest(observation, goals, avoid=danger(observation))

route() returns (move, distance), or ("stay", None) when no route exists. Distance estimates travel to a target's current tile. A moving target may escape: predicting its next junction is a useful improvement, as the Ambusher demonstrates.

Useful helpers

me() finds you. destination() handles walls, tunnels and teleports; action_positions() predicts both steps of a predator burst. nearest() chooses a shortest path. danger() lists current threats. emergency() uses a short graph search to find an escape. pickups() filters available items. hunt() handles timed pursuits of edible players or frightened ghosts. Read and modify these helpers as part of the lesson.

05 / POWER CHANGES PRIORITIES

The right move depends on who can eat whom.

CLASSIC REVERSAL

Power pellets

The large cream dots award 50 points and make roaming ghosts blue for 8 seconds. Any player can eat a blue ghost for 200. Stations recharge after 40 seconds.

Helping the whole maze can also help your rivals. When should you trigger it?

PLAYER VS PLAYER

Predator power

Red P diamonds give 6 seconds of predator power, with faster straight-corridor movement. Eat an unshielded, non-predator player to transfer up to 75 of their points. Stations recharge after 24 seconds.

Can you intercept prey before your timer runs out—and still avoid dangerous ghosts?

ESCAPE ROUTES

Paired teleports

Enter A or B to emerge at its matching portal across the maze. Standing still does not retrigger it. Ghosts cannot follow through portals. The side tunnel wraps for everyone.

Can a shortcut reverse a chase? Should an ambusher guard an exit?

LOWER-RISK REWARD

Bonus cherries

The fruit below the ghost pen awards 100 points and reappears after 12 seconds. It can be worth more than a long, uncertain chase.

Is a guaranteed reward better than the possibility of eating another player?

Predator rules that matter to your code

  • Ghosts can still eat a predator. Only a power pellet turns ghost danger into an opportunity. Ghost combat resolves before player combat. Pickups and collisions are checked on both steps of a corridor burst.
  • Predators cannot eat each other. Picking up a red P can be a defensive response as well as an offensive one.
  • A shield prevents both being eaten and attacking. After a one-second respawn delay, players get three seconds to leave their spawn. Initial shields last two seconds.
  • Power is lost on death. A reckless chase can waste the entire pickup.
  • Scoring transfers existing points. Eating a zero-score player earns zero. Repeatedly farming a respawn does not create points.
  • Two hunters, one victim: rotating player priority chooses one recipient. Two agents collecting one power-up also have one rotating winner.

All four elements can be switched on or off in Settings for the next round. Ghosts remain present. Start a first lesson with predator power off, then enable it and compare what the same agents do.

06 / DEBUG WITH EVIDENCE

Slow the chase down to one decision.

  • Pause, then Step One Tick. Follow a single decision. Select an agent to see its position, signal, deaths, captures and last error. Predator countdowns appear in the leaderboard.
  • Listen to the state changes. Chomps, power, ghost captures, player captures and teleports have distinct cues. Sound and volume are in Settings; audio pauses when the app is inactive or the round is paused.
  • Wrong Python? Choose the Python 3.9+ executable you use for your code. For a virtual environment, select bin/python.
  • Broken import or missing decide? The roster displays the startup failure and other agents keep playing.
  • Invalid move or exception? Your player stays on that tick; three faults stop the policy. One deadline miss stops its process immediately, keeping a hung function from freezing everyone.
  • Slow search? One breadth-first search can find the nearest of many targets. Cache stable map work in memory. A larger common decision budget is available for teaching.
  • Use signals for live debugging. Return a short message with the move. Ordinary prints are drained separately, not shown as a live console.
  • Export the round. JSON includes configuration, final state, accepted actions and stopped-agent IDs, so you can distinguish strategy problems from runtime faults.

Run a batch from the starter-kit folder

python3 runner.py --config sample-config.json --headless --result result.json

Edit the roster, seed, toggles, tick count or budget in sample-config.json. The headless host supports macOS and other POSIX systems. The graphical display and sound are macOS features. With a fixed roster and accepted action sequence, the simulation is deterministic; unseeded student randomness and real-time deadlines can still change which actions are accepted.

Trust submitted code. Policies run with your local user's file and network permissions. Process separation and deadlines handle ordinary mistakes; they are not a security sandbox.

07 / TEACH THE CHANGE IN STRATEGY

Start with dots. Introduce the food chain.

TimeBuildDiscuss
0–15 minForage with predator power off.How do walls, ghosts and tunnels change the shortest safe path?
15–30 minUse power pellets and chase blue ghosts.Why is helping everyone sometimes individually profitable?
30–45 minEnable predators; add a threat check.When does your agent become prey? Does its current goal still make sense?
45–60 minUse timers, interception or an exit ambush.How much reward do you lose on unsuccessful hunts?

Keep the roster, round length and budget fixed. Compare several seeds, rotate starting slots, and report deaths and captures alongside score. Do not declare a universal winner from one run: the usefulness of a hunter depends on how opponents escape.

Stretch projects

  • Predict a target's next junction, not just its next tile.
  • Route around a predator's possible future positions.
  • Publish a signal before collecting a shared power pellet; coordinate ghost hunting.
  • Estimate expected points per tick, including the cost of dying or wasting a power-up.
  • Compare runs with and without predator power using exported metrics.
